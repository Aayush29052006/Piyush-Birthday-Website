# Piyush-Birthday-Website

A cinematic, ten-chapter birthday website for Piyush — 31 October 2026.

The site lives in [`Piyush-Birthday-2026/`](Piyush-Birthday-2026/) (Vite + React + TypeScript).

## Run locally
```
cd Piyush-Birthday-2026
npm install
npm run dev
```

## Publishing
Every push to `main` builds the site and publishes it with GitHub Pages
(`.github/workflows/pages.yml`).
